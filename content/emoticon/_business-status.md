# 카카오톡 이모티콘 사업 — 현황 (제출·승인·판매 진행률)

> 성과리뷰팀(REVIEW)이 캐릭터별 제출/승인/판매에 진척이 있을 때마다 이 파일을 갱신한다.
> 카카오 이모티콘 스튜디오에서 직접 확인한 값만 적는다 — 추정치·희망수치 금지
> (`MY_COMPANY.md` 절대 규칙 ⑥). `content/youtube/_channel-status.md`와 같은 패턴이며,
> 영상별이 아니라 **사업 전체 1개 파일**로 관리한다.
>
> 캐릭터·세트별 검수 상세는 `content/emoticon/<슬러그>/qa.md`·`submission-checklist.md`가
> 원본이다. 이 파일은 그 결과를 사업 전체 관점에서 한눈에 보기 위한 요약이지, 판정을 다시
> 만들지 않는다.

## 작가 계정·정산 설정 체크리스트 (한 번만 하면 됨)

카카오 이모티콘 스튜디오는 메뉴 구성·필요 서류가 시기에 따라 바뀔 수 있다 — 아래는 일반적으로
알려진 항목이며, **각 항목은 실제 화면에서 대표가 직접 재확인한다** (`qa.md`가 여러 차례 기록한
대로 공식 사이트는 이 파이프라인의 웹 조회 도구로 안정적으로 열리지 않는다):

- [ ] 카카오 계정으로 이모티콘 스튜디오 작가 등록 여부 확인
- [ ] 정산 받을 계좌 등록 여부 확인
- [ ] 세금 신고용 정보(개인/사업자) 등록 여부 확인
- [ ] 최초 제출 전 `emoticonstudio.kakao.com`에서 현재 제출 규격(개수·이미지 크기·용량) 최종
  재확인 — `qa.md` 기준 공식 원문 직접 확인이 여러 차례 실패했으므로 특히 중요

## 최근 갱신

- 갱신일: 미연동 (아직 실제 제출 전 — 첫 제출 이후 첫 갱신부터 날짜 기입)
- 확인 방법: 카카오 이모티콘 스튜디오 → 작가 페이지 → 승인 현황 / 매출 현황

**제출 전 남은 필수 확인 사항** (`qa.md`·`submission-checklist.md` 인용 — 이 두 가지가 끝나기
전에는 실제 제출을 진행하지 않는다):

1. 캐릭터 실루엣 육안 대조 — 경쟁 캐릭터(농담곰/담곰이, 백곰입니다)와 실제 유사성이 없는지
   그림 완성 즉시 대표가 직접 대조
2. 카카오 스튜디오 공식 규격 원문 재확인 — 서드파티 수치(정지형 32종/360×360px/PNG)는 공식
   사이트 직접 확인이 4회 연속 실패한 잠정치

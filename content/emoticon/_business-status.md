> 만들지 않는다.

## 작가 계정·정산 설정 체크리스트 (한 번만 하면 됨)

카카오 이모티콘 스튜디오는 메뉴 구성·필요 서류가 시기에 따라 바뀔 수 있다. 2026-08-15
공식 작가 안내서·고객센터에서 정책·기본정보·절차는 확인했으나, 유형별 이미지 가이드 표는
동적 화면에서 항목이 표시되지 않았다. 따라서 **파일 개수·크기·용량은 실제 제안 화면에서
대표가 최종 재확인한다**:

- [ ] 카카오 계정으로 이모티콘 스튜디오 작가 등록 여부 확인
- [ ] 정산 받을 계좌 등록 여부 확인
- [ ] 세금 신고용 정보(개인/사업자) 등록 여부 확인
- [ ] 최초 제출 전 `emoticonstudio.kakao.com`에서 현재 제출 규격(개수·이미지 크기·용량) 최종
  재확인 — 공식 이미지 가이드 URL은 확인했지만 표 내용이 표시되지 않아 미확인
- [x] 생성형 AI 관련 공식 운영 원칙 확인 — 2026-08-15 확인. 대표가 AI 제작 경로를 선택했으며
  AI 산출물은 SNS·굿즈·브랜드 IP용으로 사용하고 카카오 제출은 보류

## 현재 단계

`AI 콘셉트 5안 → 2안 승인 → 마스터 시트 → 파일럿 8종 → 1호 기본 32종 완료 → 상품화 후처리`

대표가 제작팀 판단에 위임해 2안을 승인했다. 마스터 시트, 파일럿 8종, 기본 세트 작업용 PNG
32종은 2026-08-15 생성·보관을 마쳤다. 현재 병목은 **투명 배경·문구 레이어·64px/흑백 검수와
상품별 규격화**다. 공개 이미지 1차 유사성 대조는 통과했지만 법률·상표 검토는 아니다. AI 제작·
활용 기준은 `gyeotgom/ai-production-plan.md`를 따른다.

완료된 준비:

- 공식 생성형 AI 정책·작가명/시리즈명/이모티콘명 글자 수·심사 기간·통계 항목 확인
- 카카오 이모티콘샵에서 "곁곰" 정확 검색 결과 없음 확인(2026-08-15, 상표 검색을 대신하지 않음)
- 1호 문구·상황 32종과 제출 문구 초안 정리
- AI 캐릭터 콘셉트 보드 5안 생성
- 2안 승인 및 정면·측면·후면·표정 6종 마스터 시트 생성
- 기본 세트 파일럿 8종 생성 및 무문구 가독성 1차 확인
- 기본 세트 작업용 PNG 32/32 생성, 번호 누락·중복·파일 손상 없음 확인

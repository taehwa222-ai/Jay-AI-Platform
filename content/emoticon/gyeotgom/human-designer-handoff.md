# 곁곰 1호 — 사람 디자이너 전달 패키지

> **현재 비활성:** 대표가 AI 제작을 선택해 외주 문의·계약을 진행하지 않는다. 카카오 제출용
> 사람 창작 경로가 다시 필요할 때만 사용한다.
>
> 상태: 견적·제작 의뢰 준비 완료 / 실제 발송·계약·결제 전 대표 확인 필요
> 대상: `set-basic-32.md` 1호 MVP

## 한 줄 의뢰

생성형 AI를 전혀 사용하지 않고, "말없이 곁을 지키는 작은 곰"이라는 텍스트 콘셉트에서 출발해
카카오톡 정지형 이모티콘용 독립 캐릭터를 사람의 손으로 새로 디자인해 주세요.

## 제공할 문서

- `character.md`의 **유지할 콘셉트**와 표정·사용 가이드
- `design-reboot-brief.md`
- `set-basic-32.md`

제공하지 않을 것:

- 기존 ChatGPT Image v3.0 이미지
- `image-prompts-basic.md`, `image-prompts-monday.md`
- `image-generation-notes.md`에 기록된 AI 생성 결과

## 견적을 나눠 받을 범위

| 단계 | 산출물 | 다음 단계 조건 |
|---|---|---|
| A | 흑백 실루엣 5안 + 정면 얼굴 + 안별 고유 특징 2개 | 대표가 1안 승인 |
| B | 턴어라운드 + 감정 6종 + 파일럿 8개 + 64px/흑백 테스트 | 아트 검수 통과 |
| C | 1호 정지형 32종 최종 아트와 제출용 파생 파일 | 공식 규격 재확인 후 제작 |

A·B·C의 가격과 일정을 분리해 요청한다. A 승인 전에는 B·C 비용을 집행하지 않는다.

## 필수 제작 조건

- 이미지 생성·변환·생성형 채우기·AI 리터치·AI 업스케일 미사용
- 기존 AI v3.0 또는 경쟁 캐릭터를 베끼거나 변형하지 않은 독립 디자인
- 직접 편집 가능한 원본 레이어 파일과 중간 스케치 제공
- 사용한 폰트·브러시·소재 목록과 상업 이용 근거 제공
- 제안용 아트와 최종 제작물의 캐릭터 형태가 크게 달라지지 않도록 일관성 유지
- 각 단계의 제작 날짜와 수정 이력이 확인되는 작업 파일 보관

## 계약 전 확인 목록

- [ ] A·B·C 단계별 금액과 수정 횟수
- [ ] 납기와 지연 시 처리 방식
- [ ] 카카오 이모티콘 판매·홍보·후속 시리즈·굿즈에 필요한 이용 범위가 계약서에 명시됐는지
- [ ] 원본 레이어 파일과 중간 스케치 전달 여부
- [ ] 제3자 폰트·브러시·소재의 라이선스 책임과 증빙 전달 여부
- [ ] 생성형 AI 미사용 확인 문구
- [ ] 포트폴리오 공개 시점과 공개 가능한 이미지 범위
- [ ] 세금계산서·현금영수증 등 비용 증빙 방식

권리 범위와 세무 처리는 계약 상대·사업 형태에 따라 달라질 수 있으므로, 실제 계약 문구는
대표가 확인하고 필요하면 전문가 검토를 받는다.

## 작가에게 보낼 문의 초안

안녕하세요. 카카오톡 정지형 이모티콘 1세트를 준비하고 있습니다. 기존 이미지를 참고하지 않고
텍스트 콘셉트부터 독립적으로 새 캐릭터를 디자인하는 작업이며, 생성형 AI를 전 과정에서 사용하지
않는 조건입니다.

먼저 흑백 실루엣 5안(A단계) 견적을 받고, 1안 선정 후 턴어라운드·감정 6종·파일럿 8개(B단계),
검수 통과 후 정지형 32종(C단계)으로 진행하려 합니다. 각 단계의 금액·예상 기간·포함 수정 횟수,
원본 레이어 및 중간 스케치 전달 가능 여부, 사용 폰트·브러시·소재의 상업 이용 증빙 가능 여부를
알려주세요.

카카오 이모티콘 판매와 후속 시리즈·홍보·굿즈 활용에 필요한 권리 범위도 계약서에 명시하고
싶습니다. 가능한 일정과 포트폴리오를 함께 부탁드립니다.

## 수락 기준

다음 중 하나라도 충족하지 못하면 다음 단계로 넘어가지 않는다.

- 생성형 AI 미사용을 명확히 확인할 수 있음
- 원본 레이어·중간 스케치 제공 가능
- A·B·C 단계별 견적과 수정 횟수가 분리됨
- 상업 이용 가능한 폰트·브러시·소재만 사용
- 대표 승인 게이트를 받아들임

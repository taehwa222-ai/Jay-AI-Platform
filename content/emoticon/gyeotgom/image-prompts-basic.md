# 곁곰 1 (기본 컬러 32종) — AI 이미지 생성 프롬프트

> `character.md` 디자인 기준을 그대로 반영. ChatGPT Image, Midjourney, Gemini 등 어떤 도구를
> 써도 되지만, **32장 전부 같은 대화(같은 세션/같은 참조 이미지)에서 이어서 생성**하거나,
> 매번 아래 "공통 스타일 블록"을 그대로 붙여넣어야 캐릭터가 흩어지지 않는다. 가능하면 이미
> 있는 마스터 디자인 이미지(정면·옆·뒤·위 시점 시트)를 참조 이미지로 함께 첨부한다.

## 공통 스타일 블록 (모든 프롬프트 앞에 붙일 것)

```
귀여운 카카오톡 이모티콘 스타일 캐릭터 일러스트. 사랑받아 살짝 낡은 듯한 순백색 곰
캐릭터 "곁곰". 동그란 단추 눈, 크고 둥근 코(얼굴 중앙보다 살짝 아래 위치), 한쪽 귀가
살짝 접혀 있음, 통통한 손과 발. 입은 없음 — 표정은 오직 눈 모양으로만 표현하고 절대
입이나 이빨을 그리지 않는다. 컬러: 몸통은 흰색~아이보리(#FFFFFF, #F4F4F4, #EDEDED),
눈·코는 짙은 블랙(#111111), 담요·소품에만 포인트 핑크(#F7B7C7) 사용. 선은 단순하고
부드럽게, 그림자는 최소한으로. 배경은 투명 또는 순백색 단색. 정사각형 캔버스(1:1),
캐릭터를 중앙에 꽉 차게. 이미지 안에 어떤 텍스트나 말풍선도 넣지 않는다.

**중요**: 얼굴 표정은 절제하지만(입 없음 유지), 팔·손·몸의 자세와 각도는 크고 분명하게
그려서 멀리서도 감정이 바로 읽히게 한다 — 어중간하거나 미묘한 자세는 피한다
(`approval-improvements.md` 2026-08-09 결정: 라이언 캐릭터처럼 "표정은 조용해도 동작으로
감정이 확실히 전해지는" 방식).
```

## 표정(눈 모양) 참고

- **평상시**: 동그랗고 담담한 눈
- **졸림**: 반쯑 감긴 눈, 아래로 처짐
- **삐짐**: 눈꼬리가 살짝 올라가고 미간이 좁아짐
- **감동/공감**: 눈이 살짝 커지고 촉촉해 보임
- **반짝**: 눈에 별 모양 하이라이트
- **당황**: 눈이 동그랗게 커지고 눈썹(있다면 눈 위 라인)이 위로

## 사용 순서 제안

1. 먼저 #1(엄지 척)로 스타일이 마스터 디자인과 맞는지 1장 테스트 생성.
2. 맞으면 같은 세션/같은 참조 이미지로 나머지 31장을 이어서 생성 (매번 공통 스타일 블록 반복).
3. 완성되면 `qa.md`·`submission-checklist.md`가 지목한 담요 등장 6개(#8·10·11·21·23·26)부터
   농담곰(담곰이)과, 전체 실루엣을 백곰입니다과 육안 대조.
4. 정사각형(360×360px 권장, 제출 전 카카오 스튜디오에서 재확인) · PNG · 배경 투명으로
   내보내기.

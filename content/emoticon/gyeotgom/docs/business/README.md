# 곁곰 사업 관리

세트 진행 상태의 기계 판독 원본은 `../../metadata/business-status.json`이다.

```text
아이디어 → 제작중 → 검수 → 최종확정 → 제출준비 → 제출 → 심사 → 승인/반려 → 출시
```

현재 등록 상태:

- 기본 32종: 검수
- 월요일의 곁곰 32종: 아이디어

로컬 미리보기에서 상태와 개별 검수 메모를 변경할 수 있다. 해당 변경은 원본 보호를 위해
브라우저 저장소에만 기록되며, “검수 데이터 내보내기”로 JSON을 내려받아 소유자가 확인한 뒤
정식 데이터에 반영한다.

실제 제출·승인·판매 이력은 상위 `content/emoticon/_business-status.md`에 직접 확인된 사실만
기록하는 기존 원칙을 유지한다.

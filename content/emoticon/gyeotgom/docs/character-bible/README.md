# 곁곰 캐릭터 바이블

이 문서는 기존 `character.md`와 세트 기획 문서를 찾아보기 쉽게 재구성한 색인이다. 기존 이미지나
제작 기록의 권리·출처를 새로 판단하지 않는다. 시각 기준은 소유자가 확정한 실제 원본을 우선한다.

## 캐릭터 정의

- 이름: 곁곰(Gyeotgom)
- 한 줄 소개: “언제나 네 곁에.” 조용히 곁을 지켜주는 작은 곰
- 정체성: 사랑받아 조금 낡은, 멍한 백곰
- 핵심 성격: 조용함, 다정함, 공감형
- 주요 대상: 과장되지 않은 조용한 위로를 선호하는 사람, 특히 지친 20~30대 직장인
- 말투: 짧고 조용한 편

## 외형·표현 규칙

- 입이 없으며 눈과 몸짓으로 감정을 전달한다.
- 얼굴, 신체 비율, 귀, 봉제선, 색상, 눈 위치의 일관성을 유지한다.
- 담요는 일부 상황에서 쓰는 소품이며 캐릭터 식별성 전체를 대신하지 않는다.
- 축소·흑백·얼굴 크롭 상태에서도 같은 캐릭터로 식별되는지는 사람이 별도로 검수한다.
- 과거 폐기 시안의 세부 규칙은 `character.md`의 보관 기록을 따른다. 이 문서에서 복원하지 않는다.

## 성격과 세계관

- 말보다 곁에 있어 주는 행동으로 위로한다.
- 특기는 토닥토닥과 잠들어 주기다.
- 담요, 따뜻한 우유, 햇살, 편안한 공간을 좋아한다.
- 화요일, 알람, 야근을 싫어한다.
- 과장된 개그보다 공감, 휴식, 다정한 일상 반응에 집중한다.

## 주요 감정과 대표 행동

| 감정 | 대표 표현 |
|---|---|
| 평온·안심 | 웃음, 눈 감기, 따뜻한 우유 |
| 공감·위로 | 귀 기울이기, 토닥이기, 안아주기 |
| 피곤·무기력 | 엎드리기, 멍하게 보기, 상자 안에 앉기 |
| 인사·긍정 | 엄지 척, 손 흔들기, 끄덕이기 |
| 놀람·당황 | 눈 모양과 자세 변화 |
| 삐짐·거절 | 팔짱, 손 저어 거절하기 |

## 금지·주의 표현

- 입을 새로 그려 감정을 표현하지 않는다.
- 폭력적이거나 공격적인 반응으로 성격을 바꾸지 않는다.
- 긴 대사나 과장된 고함으로 조용한 말투를 훼손하지 않는다.
- 과거 폐기 시안을 새 제작의 시각 레퍼런스로 되살리지 않는다.
- 소유자 확인 없이 이미지 내용, 제작 이력, 권리 표기를 변경하지 않는다.

## 흑화 곁곰

현재 별도의 완성 이미지가 없다. `set-monday-32.md`에 “월요일의 곁곰” 흑백 32종의 상황과
문구만 있으며, 기본 세트 검증 전 제작 보류 상태다. 따라서 흑화 버전은 이미지 자산이 아니라
기획 상태로 관리한다.

## 기존 확장 아이디어

기존 `character.md`에 기록된 범위는 인형, 키링, 스티커, 스마트톡, 메신저 프로필,
배경화면, 다이어리 스티커, 머그컵이다. 모두 아이디어 상태이며 실제 제작물로 간주하지 않는다.

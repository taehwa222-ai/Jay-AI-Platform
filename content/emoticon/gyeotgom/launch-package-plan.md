## 2. 우선 사용할 대표 컷

- 인사·업무: #1 오키, #2 확인, #5 커피, #6 퇴근
- 공감·위로: #17 고마워, #20 보고싶어, #21 토닥토닥, #27 그랬구나, #30 안아줄게
- 감정·휴식: #8 살려줘, #23 잘자, #31 좋은 아침

첫 공개는 12개만 사용한다. 32개를 한꺼번에 공개하지 않고 저장·공유 반응이 높은 장면을 먼저
확인한 뒤 상품 구성을 결정한다.

`../_business-status.md`와 `review.md`에 남긴다.

## 4. 상품 우선순위

1. 무료 PNG 샘플 6종 — 이름과 사용 맥락 검증
2. 디지털 배경화면 3종 — 재고 없이 색·장면 선호 검증
3. 소량 스티커 시트 1종 — 상위 8~12컷만 사용
4. 엽서 3종 — 위로 문구 중심
5. 아크릴·봉제 등 단가 높은 제품 — 선주문 근거가 생긴 뒤 검토

가격은 경쟁 상품의 표시가가 아니라 실제 견적의 제작비·포장비·결제 수수료·배송·불량률을
합산한 원가표를 만든 뒤 정한다. 수요 검증 전 대량 발주하지 않는다.

## 6. 중단 조건

- 유사 캐릭터 권리자 또는 플랫폼에서 구체적 이의를 제기함
- 64px에서 비대칭 귀·눈 패치가 사라져 일반 흰 곰과 구분되지 않음
- 배경 제거 과정에서 털 외곽 품질을 안정적으로 유지할 수 없음
- 실제 선주문 없이 최소 발주 수량이 큰 인쇄·봉제 상품만 남음

중단 조건이 생기면 신규 상품 제작을 멈추고 디자인 수정 또는 디지털 상품 중심으로 경로를
바꾼다. 카카오 이모티콘 제출은 생성형 AI 활용 제한이 공식적으로 바뀌기 전까지 별도 보류다.

# 곁곰 이미지 자산 보존 안내

이 폴더의 기존 이미지 파일은 원본으로 취급한다. 자산 관리·검수 도구는 이 파일을 읽기만 하며
이름 변경, 이동, 덮어쓰기, 삭제, 리사이즈, 포맷 변환을 하지 않는다.

## 현재 분류

| 관리 분류 | 현재 경로 | 상태 |
|---|---|---|
| 이모티콘 원본 | `ai-basic-32/` | 기본 세트 PNG 32개 |
| 캐릭터 마스터 | `ai-master/` | PNG 1개 |
| 참고 콘셉트 | `ai-concepts/` | PNG 1개 |
| 제작 파일럿 | `ai-pilots/` | PNG 9개, 기본 세트와 동일 해시 파일 포함 |
| 흑화 버전 | - | 이미지 없음 |
| 친구 캐릭터 | - | 이미지 없음 |

`ai-*`라는 기존 경로명과 기존 제작 기록은 출처 추적을 위해 그대로 보존한다. 폴더명의 의미나
자산 권리를 이 문서에서 새로 판단하지 않는다.

구조화된 자산 목록은 `../metadata/emoticon-manifest.json`, 실행 시점의 기술 검수 결과는
`../output/reports/`에서 관리한다.

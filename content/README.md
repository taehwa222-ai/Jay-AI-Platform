# content/

대표(사용자)의 개인 콘텐츠 제작 파이프라인 결과물을 모아두는 폴더다. 이 프로젝트의 앱 코드
(`backend/`, `frontend/`)와는 별개이며, `/yt-pipeline` 및 `.claude/agents/yt-*.md` 에이전트가
여기에 결과를 저장한다. 운영 규칙(부서 기준·승인 지점·상태 표기)은 루트 `MY_COMPANY.md` 를
따른다.

```
content/youtube/<날짜>-<소재-슬러그>/
  research.md    시장조사팀 결과 (트렌드 후보 5개 + 출처)
  ideas.md        기획1팀 결과 (아이디어 10개 → TOP3 점수표)
  qa.md            브랜드검수팀 결과 (통과/반려 + 사유)
  script.md       기획2팀 결과 (승인된 안 1개의 대본)
  production.md   영상제작팀 결과 (컷 구성 + 자막 초안 + 촬영 메모 + 롱폼이면 숏폼 재활용
                   컷 지정 + 커뮤니티 게시글 초안)
  review.md       성과리뷰팀 결과 (게시 후 성과 기록, 있으면 — 아래 템플릿 참고)

content/youtube/_channel-status.md   채널 전체 수익화 자격 진행률 (영상별이 아니라 1개 파일)
```

- 실제 영상·이미지 원본 파일은 여기 두지 않는다 (용량 문제) — 기획 문서만 커밋한다.
- 대표 승인 전 단계(`research.md`~`ideas.md`)까지는 자유롭게 진행하지만, `script.md` 는
  대표가 TOP3 중 1개를 승인한 뒤에만 만든다 (`MY_COMPANY.md` §3-★대표 승인).

## `review.md` 템플릿 (성과리뷰팀 — 게시 48시간 이후 작성)

유튜브 스튜디오 값을 그대로 옮겨 적는다. 확인 안 한 항목은 빈칸이 아니라 '미연동'이라고 쓴다
(`MY_COMPANY.md` 절대 규칙 ⑥).

```markdown
# review.md — <날짜-소재>

## 유튜브 스튜디오 복붙 표
| 항목 | 수치 |
|---|---|
| 조회수 | |
| 노출 대비 클릭률(CTR) | |
| 평균 시청 지속시간 | |
| 구독자 증감 | |
| 좋아요 / 댓글 / 공유 | |
| 트래픽 소스 1위 | |

## 패턴 한 줄
- 잘된 이유:
- 안 된 이유:

## 다음 기획 반영
- 반복할 것 1개:
- 중단할 것 1개:

## 채널 누적 현황
- `content/youtube/_channel-status.md` 갱신 여부: [ ] 완료
```

`_channel-status.md` 는 영상 1개가 아니라 채널 전체 수익화 자격(구독자·시청시간) 진행률을
추적하는 파일이라 폴더 밖에 딱 1개만 둔다. 형식은 그 파일 자체를 참고한다.

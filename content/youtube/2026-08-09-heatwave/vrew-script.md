# vrew-script.md — Vrew "텍스트로 영상 만들기" 붙여넣기용

> `script.md`(대본)를 Vrew의 텍스트-투-비디오 입력 형식에 맞게 다듬은 버전이다. 이 문서
> 자체는 파이프라인 공식 산출물이 아니라 촬영·편집을 대신할 실무 자료다.

## 사용 순서

1. Vrew 실행 → "텍스트로 비디오 만들기" 선택
2. 아래 "붙여넣을 본문" 을 통째로 붙여넣기 (문단 구분은 그대로 유지 — Vrew가 문단 하나당
   장면 하나로 나눠 이미지를 자동 매칭한다)
3. AI 목소리 선택: **20~30대, 밝고 통통 튀는 톤**으로 고르기 — `MY_COMPANY.md` §2 말투
   ("빠르고 캐주얼한 트렌드 캐스터")와 맞추기 위함. 후보를 2~3개 미리듣기 해보고 결정할 것
4. 생성 후 각 장면 이미지가 아래 "장면 키워드"와 안 맞으면, 그 장면만 클릭해 키워드로
   재검색/교체 (전체를 다시 만들 필요 없음)
5. 자동 생성된 자막이 아래 "자막 원문"과 다르면 원문 기준으로 고쳐서 오타·띄어쓰기 정리
6. 완성 후 다운로드 — 이 시점부터는 대표가 직접 확인하고 업로드

## 붙여넣을 본문 (문단 구분 유지)

```
오늘 화제는 이겁니다. 프로야구가, 날씨 때문에 통째로 멈췄어요.

KBO 역사상 처음이에요. 8월 5일부터 오늘 8월 9일까지, 닷새 동안 1군 전 경기가 전부
취소됐습니다. 비도 아니고, 태풍도 아니고, 더위 때문에요.

시작은 8월 4일, 인천 경기였어요. 경기 도중 관중 한 명이 온열질환으로 쓰러졌습니다.
바로 다음 날, KBO가 결단을 내렸어요. "이대로는 안 된다" — 리그 전체를 세운 겁니다.

정리하면, KBO는 8월 6일 긴급 실행위원회를 열고 8월 11일 리그를 다시 시작하기로
했어요. 그런데 그냥 재개가 아닙니다. 9월 6일까지 전 경기를 오후 7시로 늦추고,
3회·7회에 쉬는 시간, 쿨링브레이크를 넣기로 했습니다.

역대급 폭염, 야구도 못 하는데 저는 오늘도 출근했네요. 이건 알아두면 좋아요.
오늘이 중단 마지막 날입니다. 저장해두세요.
```

## 장면별 키워드 (자동 이미지가 안 맞을 때 재검색용)

| 문단 | 장면 키워드 |
|---|---|
| 1 (훅) | 야구장, 텅 빈 관중석, 폭염 |
| 2 (문제) | 달력 8월, 취소, KBO 로고 |
| 3 (원인) | 온열질환, 응급차, 더위 |
| 4 (해결) | 시계 오후 7시, 야간 경기, 쿨링브레이크 |
| 5 (CTA) | 직장인 출근, 부채질, 저장 아이콘 |

## 자막 원문 (Vrew 자동 자막이 다르면 이 기준으로 고칠 것)

1. "역대급 폭염에 KBO 전경기 중단"
2. "8/5~8/9 1군 전 경기 취소 (KBO 역대 최초)"
3. "8/4 인천 경기 중 관중 온열질환 → 8/5 KBO '폭염 휴식기' 결정"
4. "8/11 재개, 9/6까지 전 경기 오후 7시 시작 + 3·7회 쿨링브레이크 (KBO 실행위 발표,
   코리아데일리 보도 인용)"
5. "오늘(8/9) 중단 마지막 날 — 내일부턴 다시 뜨거운 밤 야구"

> 직접 확인한 값만 적는다 — 추정치·희망수치 금지 (`MY_COMPANY.md` 절대 규칙 ⑥).

## 채널 최초 설정 체크리스트 (한 번만 하면 됨)

채널을 아직 만들지 않았다면(2026-08-09 기준 미개설) 첫 영상 업로드 전에 아래를 확인한다.
메뉴 이름·위치는 유튜브 스튜디오 업데이트로 바뀔 수 있으니 실제 화면에서 확인한다.

- [ ] 구글 계정으로 채널 생성 — `@핸들` 사용 가능 여부 확인 후 `MY_COMPANY.md` §0 확정
- [ ] 프로필 사진 업로드
- [ ] 채널 배너(아트) 업로드
- [ ] 채널 설명 작성 — §0 "한 줄 정체성" 문구 활용
- [ ] 업로드 기본값 확인: 카테고리, 댓글 설정, **"아동용 아님"으로 설정** (광고 수익에 직접
  영향 — 잘못 설정하면 개인 맞춤 광고가 제한돼 수익이 크게 줄어든다)
- [ ] 연락처(문의용 이메일) 등록 여부 결정
- [ ] 수익화(유튜브 파트너 프로그램) 신청 경로 확인 — YouTube Studio → 수익 창출 탭. 아래
  진행률 표 기준을 채운 뒤에만 신청 가능

## 최근 갱신

- 갱신일: 미연동 (아직 채널 개설 전 — 채널 개설 후 첫 갱신부터 날짜 기입)
- 확인 방법: YouTube Studio → 채널 → 수익 창출 탭 (studio.youtube.com)

## 유튜브 파트너 프로그램(YPP) 자격 진행률

> 요건은 시기별로 바뀔 수 있으니 갱신할 때마다 YouTube 공식 고객센터에서 최신 기준을
> 재확인한다. 아래는 2026-08-09 기준으로 확인된 요건이다.

| 항목 | 목표 | 현재 | 진행률 |
|---|---|---|---|
| 구독자 | 1,000명 | 미연동 | - |
| 공개 시청시간 (최근 365일) | 4,000시간 | 미연동 | - |
| 또는 Shorts 조회수 (최근 90일) | 1,000만 회 | 미연동 | - |

- 시청시간 4,000시간 **또는** Shorts 조회수 1,000만 회, 둘 중 하나만 충족하면 된다.
- 채널을 아직 개설하지 않아 전 항목 미연동 — 채널 개설 후 첫 영상 게시 시점부터 갱신 시작.

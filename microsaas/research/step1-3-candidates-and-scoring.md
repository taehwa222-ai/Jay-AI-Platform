# Micro SaaS 후보 발굴 — STEP 1~3 결과

- 작성일: 2026-08-15
- 범위: STEP1(30개 이상 후보 발굴 + 시장 증거) → STEP2(근거 수집, 각 후보에 포함) → STEP3(100점 평가 → TOP 10)
- 방법: 7개 병렬 리서치 에이전트(쇼핑/중고, 여행/반려동물/취미, 생산성/개발자, 금융/부동산, 취업/교육, 해외유료-한국공백 패턴A, 불만많은기존서비스 패턴B/G)가 실제 WebSearch/WebFetch로 조사. 2개 에이전트는 1차 시도에서 조직 월간 사용한도 초과로 실패 → 재시도로 완료.
- 총 42개 원본 후보 → 중복/유사 아이디어 4건 병합 → **38개 최종 후보**
- 제외 원칙 준수: 기업 업무자동화·GWS대행·홈페이지제작·개발외주·AI블로그/쇼츠 대량생성·범용챗봇·프롬프트판매·전자책 대량생성·템플릿복제·광고수익전용 콘텐츠는 후보에서 원천 배제. 법률/의료/투자자문성 항목은 후보로는 남기되 "위험도" 표시.

## 평가 기준 (100점)

시장성(30) · 수익성(25) · 경쟁환경(15) · 개발가능성(15) · MVP속도(15)

## 전체 조사에서 발견한 패턴

- **"확인 필요" 표시가 많다는 것 자체가 다음 단계(TOP5 심층조사)의 할 일이다.** 특히 실제 검색량, 한국 커뮤니티 원문 인용, 지불 의사는 대부분의 후보에서 직접 확인하지 못했다.
- Chrome Extension만으로 순수 클라이언트사이드 구현이 가능한 후보(PDF 다크패턴 우회, 캐시백 증거기록기, 학술인용 삽입)가 개발가능성·MVP속도 점수에서 유리했다.
- **이중 발견(두 독립 에이전트가 각자 찾음)** 후보가 하나 있었다 — 채용사이트 지원현황 트래커. 서로 다른 조사 경로에서 같은 결론에 도달한 것은 상대적으로 강한 신호로 취급했다.
- 시의성이 있는 기회 2건 확인 — LanguageTool 유료전환(2026-07~08, 지금), Fakespot 폐쇄(2025년, 대체재 경쟁 아직 안 정해짐).
- 금융/세무/의료 인접 후보는 점수가 높아도(서학개미 세금계산기 71점, 펫보험 63점) 정책상 우선순위를 낮췄다 — 잘못된 답의 피해가 크기 때문.

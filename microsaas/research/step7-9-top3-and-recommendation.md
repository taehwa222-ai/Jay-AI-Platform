## TOP 1. 한국 채용 지원 클리퍼·트래커

### 한 줄 설명

사람인·잡코리아·원티드에서 관심 공고와 제출 자료를 사용자의 한 번 클릭으로 보관하고, 지원 상태와 후속 일정을 로컬에서 관리하는 취업 기록 도구.

### Problem / Target Persona

- 첫 타깃: 한 달에 20건 이상을 3개 이상의 채용사이트에서 지원하는 졸업예정자·취업준비생·경력 전환자.
- 공고가 내려가면 면접 전에 직무 설명을 다시 찾기 어렵다.
- 회사마다 낸 이력서 버전, 자소서 문항·답변, 희망연봉을 이메일·다운로드 폴더·노션에 흩어 저장한다.
- 반복 입력보다 더 중요한 문제는 “무엇을 어디에 냈는지”가 남지 않는 것이다.

### Existing Solution / Pain Point

- Excel·Notion·Trello: 무료지만 입력을 미루기 쉽고 공고와 제출 파일이 자동으로 연결되지 않는다.
- 직행: 국내 공고 통합과 지원 관리를 제공하지만 브라우저에서 현재 공고와 제출 버전을 로컬 기록하는 문제와는 다르다.
- Huntr·Teal·Simplify: 기능은 강하지만 한국어 문항과 국내 포털 지원을 전제로 하지 않고, 유료 플랜은 월 $29~40 수준이다.

### Differentiation

- 자동 지원 도구가 아니라 **지원 증거 금고**로 포지셔닝한다.
- 계정과 서버 없이 시작하며 이력서·자소서를 브라우저 로컬 저장소에 둔다.
- 사용자가 버튼을 누를 때만 저장하고 제출 버튼은 절대 대신 누르지 않는다.
- 공고 스냅샷, 제출 파일 해시·이름, 자소서 문항·답변, 지원일, 연락 일정이 한 카드에 묶인다.
- 한국 채용 시즌에 맞춘 30일·90일 패스를 제공한다.

### Chrome Extension 가능 여부

적합하다. 단, 자동 로그인·자동 제출·백그라운드 수집·Captcha 우회는 금지한다. DOM 자동 추출도 각 사이트 약관 검토 전에는 제목·URL과 사용자가 선택한 텍스트 수준으로 제한한다.

### 2주 MVP

#### Must Have

- Manifest V3 Chrome 확장
- 현재 URL, 제목, 회사명, 마감일을 사용자가 확인·수정한 뒤 저장
- Wishlist / 준비중 / 지원완료 / 면접 / 종료 칸반
- 공고 원문을 사용자가 선택해 보관하는 스냅샷
- 제출한 이력서 버전명과 자소서 문항·답변 기록
- 마감·후속연락 브라우저 알림
- CSV·JSON 내보내기와 전체 삭제
- 기본 로컬 저장, 네트워크 전송 없음

#### Nice to Have

- 사람인·잡코리아·원티드별 읽기 전용 필드 어댑터
- Gmail의 지원 확인 메일을 사용자가 선택해 상태 변경
- 중복 회사·공고 감지

#### Later

- 암호화 동기화와 웹 대시보드
- 여러 기기 사용
- 검증형 자소서 점검
- 대학 취업센터용 익명 진행 현황

### 가격

| 플랜 | 가설 가격 | 제한 | 업그레이드 이유 |
|---|---:|---|---|
| Free | 0원 | 활성 공고 20개, 로컬 저장, CSV 내보내기 | 핵심 문제를 충분히 체험 |
| Sprint 30 | 3,900원/30일 | 무제한 공고·스냅샷·알림 | 공채 한 사이클 집중 사용 |
| Sprint 90 | 8,900원/90일 | Sprint 30 전체 기능 | 장기 구직 비용 절감 |
| Career Center | 별도 견적 | 학생 배포·익명 통계·관리 정책 | B2B 반복매출 |

월 구독을 억지로 강제하지 않는다. 구직은 종료되는 일이므로 B2C는 기간권, 반복매출은 대학·부트캠프·커리어 코치 라이선스에서 검증한다.

### 개발기간·비용 가설

- 개발: 7~10일, 사이트 어댑터를 3개 모두 넣으면 10~14일.
- 초기 현금비용: Chrome Web Store 등록비와 도메인을 포함해 10만원 이내 가설.
- 월 운영비: 로컬 전용 MVP는 0~2만원 가설. 동기화·AI를 추가하면 별도 재산정한다.
- 개인정보: 서버 저장을 시작하는 순간 암호화, 보존기간, 삭제, 침해대응 범위가 크게 늘어난다.

### 첫 사용자 100명 확보

1. 무료 “지원 현황 CSV/Notion 템플릿”을 배포하고 확장으로 가져오기 기능을 연결한다.
2. 링커리어·취업 카페·대학 커뮤니티에서 판매 글이 아니라 공고 보존 문제 설문과 무료 베타를 모집한다.
3. 취업 유튜버·커리어 코치 10명에게 데이터가 외부로 나가지 않는 데모를 제공한다.
4. Chrome Web Store에서 `사람인 지원 관리`, `잡코리아 지원 기록`, `취업 지원 현황` 설명을 명확히 쓴다.
5. 졸업예정자·부트캠프 수료생 3개 그룹과 2주 챌린지를 운영한다.

### Go / No-Go 검증

개발 전 3일짜리 랜딩페이지와 인터뷰로 다음을 확인한다.

- 타깃 인터뷰 15명 중 8명 이상이 최근 한 달 15건 이상 지원했다.
- 8명 이상이 공고·제출 버전 분실을 실제 문제로 경험했다.
- 5명 이상이 30일권 3,900원 구매 의사를 보인다.
- 최소 3명이 환불 가능한 사전결제 또는 결제수단 없는 예약을 완료한다.
- 사람인·잡코리아·원티드 약관 검토에서 사용자 클릭 기반 저장이 허용 가능한 경계로 판단된다.

하나라도 핵심 조건이 크게 미달하면 코딩하지 않고 인터뷰로 문제를 다시 좁힌다.

### 실패 가능성과 추천하지 않을 이유

- Teal처럼 무료 추적 기능이 강한 제품이 이미 있고 직행도 국내 지원 관리를 시작했다.
- 취준생은 비용 민감도가 높고, 취업하면 바로 이탈한다.
- 사이트 DOM 변경에 따라 어댑터 유지보수가 반복된다.
- 약관상 수집·자동화 범위가 좁으면 “한 번 클릭” 가치가 약해질 수 있다.
- 따라서 사전결제 3명 없이 개발하는 것은 추천하지 않는다.

## TOP 2. DART 공시 변화 추적·근거 알림

### 한 줄 설명

새 공시를 이전 공시와 비교해 달라진 숫자·문장만 원문 근거와 함께 알려주는 사실 기반 DART 모니터.

### Problem / Target Persona

- 첫 타깃: 국내 주식 10~30종목을 직접 추적하고 공시 원문을 확인하는 개인 투자자.
- 알림은 받아도 수십 페이지에서 이전 보고와 달라진 부분을 찾는 데 시간이 든다.
- 단순 AI 요약은 빠르지만 틀린 요약을 신뢰하기 어렵다.

### Existing Solution / Differentiation

- AlphaDigest, DART Feed, 오늘의공시, Economy Reports, 텔레그램 공시봇이 이미 있다.
- 차별점은 감성·추천이 아니라 `이전 값 → 새 값`, 변화율, 원문 문단, 공시 유형별 체크리스트다.
- LLM 설명보다 OpenDART 구조화 데이터와 규칙 기반 비교를 우선한다.

### Chrome Extension 가능 여부

핵심은 서버 모니터링이라 확장만으로는 부적합하다. MVP는 작은 웹서비스와 이메일·텔레그램 알림이 적합하며, 확장은 원문 위에 전기 대비 변화를 표시하는 Later 기능이다.

### 2주 MVP

#### Must Have

- OpenDART API 키와 사용량 제한 관리
- 관심 기업 3개 등록
- 5~6개 공시 유형의 신규 제출 감지
- 이전 동종 공시와 숫자·핵심 필드 비교
- 원문 링크와 추출 근거 표시
- 일 1회 이메일 또는 텔레그램 브리핑
- 오류 시 요약을 만들지 않고 원문 확인 상태로 표시

#### Nice to Have

- 사용자 정의 금액·변화율 조건
- 정정공시와 원공시 연결
- 표준화되지 않은 문단의 제한적 LLM 보조

#### Later

- 실시간 알림
- 팀 워치리스트
- 감사 가능한 변경 이력
- 미국 SEC 확장

### 가격

| 플랜 | 가설 가격 | 제한 |
|---|---:|---|
| Free | 0원 | 3종목, 일간 브리핑, 2개 공시 유형 |
| Starter | 4,900원/월 | 20종목, 6개 유형, 조건 알림 |
| Pro | 9,900원/월 | 60종목, 빠른 알림, CSV·Webhook |

### 개발기간·비용 가설

- 개발: 구조화 공시 5~6종에 한정하면 10~14일.
- 초기 비용: 10만원 이내 가설.
- 월 운영비: 규칙 기반 소규모 베타 3~10만원, LLM 사용 시 5~20만원 추가 가능. 실제 호출량으로 다시 계산한다.

### 첫 사용자 100명 확보

- 공시 유형별 “무엇이 바뀌면 중요한가” 무료 가이드를 검색 콘텐츠로 공개한다.
- 공시 원문과 변화표가 함께 보이는 샘플 20건을 제공한다.
- 기존 주식 분석 사용자에게 별도 동의를 받아 베타를 안내한다. 기존 사용자 정보를 임의로 전용하지 않는다.
- 투자 커뮤니티 홍보는 각 커뮤니티 정책과 금융광고 규정을 확인한 뒤 사실 기반 도구로만 진행한다.

### 주요 위험과 중단 조건

- AlphaDigest와 기능·가격이 겹친다.
- 유료 양방향 개인화 또는 매매 판단으로 보이면 투자자문 규제 위험이 커진다.
- 공시 해석 오류가 사용자의 금전 손실과 연결될 수 있다.
- 20명 인터뷰에서 5명 이상이 “요약보다 변화 추적”을 주간 사용하고, 3명이 월 4,900원을 사전결제하지 않으면 중단한다.
- 금융 규제 검토 전에는 결제 기능과 감성·추천 기능을 열지 않는다.

## TOP 3. 검증형 AI 자소서 첨삭

### 한 줄 설명

자소서를 대신 쓰지 않고, 지원자의 실제 경험과 대조해 과장·누락·블라인드 위반·문항 미응답을 찾아주는 제출 전 검증기.

### Problem / Target Persona

- 첫 타깃: 한 시즌에 대기업·공기업 5곳 이상에 지원하며 문항별 자소서를 반복 작성하는 취준생.
- 범용 AI가 자연스러운 문장을 만들지만 사실을 지어내거나 회사명·직무를 혼동할 수 있다.
- 사람 첨삭은 비싸고 시간이 걸리며, 기존 AI 제품은 생성·합격률 점수 중심이다.

### Differentiation

- 빈 화면에서 생성하지 않는다.
- 사용자의 경험 원장과 자소서 문장을 대조하고 근거가 없는 주장에 확인 질문을 붙인다.
- 블라인드 채용 위반, 회사명 오기, 글자 수, 문항 요구사항, 같은 사례 반복을 결정론적 규칙으로 먼저 검사한다.
- AI 수정문은 원문과 diff로 보여주고 사용자가 선택한 수정만 반영한다.

### Chrome Extension 가능 여부

가능하지만 첫 MVP는 웹 입력창이 더 안전하고 빠르다. 채용사이트 입력창에 직접 접근하는 확장은 약관·개인정보 검토 후 Later로 둔다.

### 2주 MVP

#### Must Have

- 공고·문항·자소서 붙여넣기
- 경험 원장 3~5개 입력
- 문항 충족, 회사명·직무, 블라인드, 글자 수, 수치 근거 점검
- 확인 질문과 수정 우선순위
- 원문·수정안 diff
- 입력 즉시 또는 24시간 내 자동 삭제 옵션

#### Nice to Have

- 여러 문항 간 경험 중복도
- 지원 회사별 버전 저장
- 면접에서 검증될 가능성이 높은 주장 표시

#### Later

- TOP 1 트래커와 통합
- 전문가 리뷰 마켓
- 대학 취업센터 라이선스

### 가격

| 플랜 | 가설 가격 | 제한 |
|---|---:|---|
| Free | 0원 | 2회 검증 |
| Sprint | 4,900원/7일 | 20회 검증 |
| Season | 12,900원/30일 | 80회 검증, 버전 비교 |

### 개발기간·비용 가설

- 개발: 7~10일.
- 월 운영비: 100명 소규모 베타에서 5~20만원 가설. 입력 길이와 모델에 따라 크게 변하므로 요청당 원가 상한을 먼저 둔다.
- 가장 큰 비용은 모델보다 신뢰 가능한 평가 기준과 개인정보 처리다.

### 첫 사용자 100명 확보

- 무료 블라인드·오기 검사기를 먼저 공개한다.
- 링커리어의 자소서 첨삭 수요 글에서 10명 인터뷰를 모집하되 무단 홍보는 하지 않는다.
- 대학 취업센터와 부트캠프에 2주 테스트 코드를 제공한다.
- “합격 보장”이 아니라 제출 실수 감소를 메시지로 사용한다.

### 주요 위험과 중단 조건

- 국내 직접 경쟁이 많고 가격도 이미 7,700원부터 형성돼 있다.
- 사용자는 결과 품질을 객관적으로 판단하기 어렵고 “합격률” 주장에 불신할 수 있다.
- 민감한 경력·회사 정보가 입력되므로 보안 사고 비용이 크다.
- 단독 제품으로 먼저 만들지 않는다. TOP 1 사용자가 검증 기능을 반복 요청하고 5명이 유료 업그레이드를 예약할 때만 구현한다.

## 최종 추천: TOP 1부터, 그러나 사전결제 전에는 개발 금지

추천 제품은 **한국 채용 지원 클리퍼·트래커**다. 이유는 규제 위험이 상대적으로 낮고, 로컬 전용으로 서버 없이 핵심 가설을 검증할 수 있으며, 자소서 검증을 나중에 자연스럽게 붙일 수 있기 때문이다.

그러나 강한 추천은 아니다. 직행이 이미 국내 지원 관리를 제공하고 무료 스프레드시트·Teal 대안이 있어 지불의사가 가장 불확실하다. 따라서 다음 순서가 필수다.

1. 3일: 랜딩페이지, 90초 데모, 인터뷰 질문지 작성
2. 4일: 타깃 15명 인터뷰와 가격 테스트
3. 승인 게이트: 5명 구매 의사 + 3명 사전 예약 + 약관 경계 확인
4. 통과 시에만 7~10일 로컬 MVP 개발
5. 2주 베타 후 활성 사용자·주간 재사용·결제 전환으로 계속/중단 판단

### 성공 지표

- 설치 100명
- 첫 공고 저장 활성화율 60% 이상
- 첫 주에 3개 이상 공고 저장 40% 이상
- 2주차 재사용률 25% 이상
- 유료 전환 3명 이상
- 공고 카드당 수동 수정률 20% 이하

### 즉시 중단 또는 피벗 조건

- 인터뷰 대상 대부분이 채용사이트 자체 지원내역으로 충분하다고 답한다.
- 유료 의향 5명 또는 사전 예약 3명을 확보하지 못한다.
- 주요 사이트 약관상 사용자 클릭 기반 저장도 허용하기 어렵다.
- DOM 변경 대응이 주 2시간 이상 반복된다.
- 사용자가 트래커보다 자소서 검증에 일관되게 더 높은 비용을 지불하려 한다면 TOP 3 기능을 별도 실험한다.

# 지원로그 사전검증 실험 계획

작성일: 2026-08-15  
검증 기간: 공개일로부터 14일

## 검증할 가설

1. 국내 구직자는 채용공고 원문, 제출 서류 버전, 전형 일정을 함께 관리하는 데 반복적인 불편을 느낀다.
2. 자동 지원이 없어도 기록 보존과 버전 연결만으로 유료 가치가 있다.
3. 월 3,900원 또는 90일 8,900원은 구매 의향을 묻기에 현실적인 초기 가격대다.

## 통과 기준

14일 안에 아래 세 조건을 모두 충족하면 MVP 구현으로 진행한다.

- 문제 인터뷰 15명 완료
- 제시 가격에 명시적 구매 의향 5명 이상
- 이메일 사전예약 3명 이상

보조 지표:

- 랜딩 방문 → 사전예약 전환율 8% 이상
- 인터뷰 참여 동의율 20% 이상
- 인터뷰 15명 중 8명 이상이 최근 30일 내 6건 이상 지원

## 중단·수정 기준

- 인터뷰 10명 중 3명 미만이 공고 삭제 또는 서류 버전 혼선을 최근 경험했다면 핵심 문제를 재선정한다.
- 구매 의향은 높지만 사전예약이 0명이면 가치 제안과 신뢰 문구를 먼저 수정한다.
- 자동 제출을 요구하는 응답이 절반을 넘으면 현재의 안전한 제품 경계 안에서 대안 기능을 다시 설계한다.
- 특정 채용 포털의 약관이나 기술적 제한 때문에 공고 저장이 불가능하면 URL·사용자 입력·이메일 전달 방식으로 범위를 축소한다.

## 유입 채널과 운영

초기에는 광고보다 직접 모집을 우선한다.

1. 최근 구직 경험이 있는 지인·커뮤니티 참여자 20명에게 1:1로 인터뷰 요청
2. 취업·이직 커뮤니티에는 운영 규칙을 확인한 뒤 문제 인터뷰 모집 글 1회 게시
3. 랜딩 링크에는 채널별 UTM을 붙여 유입 출처 기록
4. 매일 신청자를 확인하고 인터뷰 동의자에게 24시간 안에 일정 제안

모집 메시지 예시:

> 최근 여러 채용 사이트를 오가며 지원한 경험이 있는 분의 이야기를 듣고 있습니다. 자동 지원 도구가 아니라, 내려간 공고와 제출 서류 버전·면접 일정을 한곳에서 관리하는 도구를 검증 중입니다. 15분 인터뷰에 참여해 주시면 실제 화면을 보여드리고 의견을 듣겠습니다. 판매나 결제 요청은 없습니다.

## 기록 양식

인터뷰마다 아래 항목을 남긴다.

- 날짜 / 참여자 코드(실명 대신 P01 형식)
- 최근 30일 지원 건수와 사용 포털
- 가장 최근에 겪은 실제 문제와 현재 해결법
- 문제 발생 빈도와 손실 시간
- 90초 데모 반응
- 월 3,900원 / 90일 8,900원 구매 의향과 이유
- 반드시 필요한 기능 / 불필요한 기능
- 다음 인터뷰 소개 가능 여부

개인 식별 정보는 이메일 외에는 수집하지 않고, 검증 종료 후 더 이상 연락할 목적이 없으면 삭제한다.

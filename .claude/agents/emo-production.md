너는 `MY_COMPANY.md` 의 **6. 영상 제작팀** 자리를 이모티콘 사업에 맞게 쓰는 부서 —
"제출 준비팀" 역할이다.

## 오늘 할 일

`character.md` · `set-*.md` · `qa.md` · `submission-copy.md` 를 종합해 제출 체크리스트를
만든다.

## 체크리스트 항목

```
[ ] 제출 형태 확정 (정지형 / 애니메이션형) — qa.md 의 개수 판정 참고
[ ] 상황·문구 최종 개수 확정 (부족하면 몇 개 더 필요한지)
[ ] 실제 그림/애니메이션 파일 제작 — 대표가 별도로 진행 (이 파이프라인은 만들지 않음)
[ ] 상품명·설명 문구 (submission-copy.md 내용 그대로 사용 가능한지 확인)
[ ] 카카오 운영 원칙 재확인 완료 여부 (qa.md 결과 인용)
[ ] emoticonstudio.kakao.com 로그인 후 제안 시작하기 → 상품 형태 선택 → 파일 업로드
```

## 기준

- ① 실제 이미지 파일을 만들거나 다루지 않는다 — 체크리스트 문서만
- ② qa.md 에서 반려된 항목이 있으면 체크리스트 맨 위에 "해결 전 제출 금지"로 표시한다

## 저장

`content/emoticon/<캐릭터-슬러그>/submission-checklist.md` 에 저장한다. 실제 제출은 대표가
브라우저로 직접 한다는 것을 마지막에 알린다.

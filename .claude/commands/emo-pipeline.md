`MY_COMPANY.md` §3-7(이미지 제작팀, 이모티콘 버전)을 사규로 삼아 아래 순서로 진행한다.
**각 단계는 별도 서브에이전트(`emo-research` / `emo-planner` / `emo-qa` / `emo-writer` /
`emo-production`)를 Agent 도구로 호출해서 수행한다.**

## 순서

1. **시장조사** — `emo-research` 호출. 트렌드 + 카카오 스튜디오 최신 규격 조사,
   `content/emoticon/<슬러그>/research.md` 에 저장.
2. **기획** — `emo-planner` 호출. 신규 캐릭터면 `character.md`, 기존 캐릭터의 새 세트면
   `set-<이름>.md` 작성.
3. **검수** — `emo-qa` 호출. 개수 판정(정지형/애니메이션형) + 운영 원칙 + 브랜드 기준 검사.
   - 반려 사유가 있으면 사용자에게 짧게 보고한다 (직접 고치지 않는다).
4. **★ 대표 승인 — 여기서 반드시 멈춘다.**
   검수 통과한 컨셉트·세트를 제시하고 승인을 요청한다. 선택지: 승인 / 수정 요청 / 보류 / 폐기.
5. **제출 문구** — 승인된 것만 `emo-writer` 에 전달해서 `submission-copy.md` 작성.
6. **제출 체크리스트** — `emo-production` 호출. `submission-checklist.md` 작성.
7. 저장된 파일 경로를 요약 보고하고, **실제 그림/애니메이션 제작과 스튜디오 제출은 대표가
   직접** 한다는 것을 다시 알린다.

## 규칙

- 4번(대표 승인) 전까지 제출 문구를 미리 쓰지 않는다.
- 검수가 2회 연속 전부 반려면 진행을 멈추고 사용자 판단을 요청한다.
- 카카오 스튜디오 제출 규격(개수·크기·형식)은 시기에 따라 바뀔 수 있다 — 매 실행마다
  `emoticonstudio.kakao.com` 을 다시 확인한다. 확인 못 했으면 "확인 못 함"이라고 명시한다.
